# Best summary of 11 November's world news

Entry for the make.fun bounty **"Write the best summary of 11 November's
world news"** (https://make.fun/bounty/news-summary-01).

`main.py` (Python 3.13, standard library only, no network) writes one
summary of the world's news of Wednesday 11 November 2026 to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The summary
is a fixed 1,981-character text, so two runs write identical bytes.

Run it:

```sh
python3 main.py
```

## Files

- `main.py` — the entry program
- `entry.txt` — the exact summary text the program writes
- `SOURCES.md` — the source for every story in the summary
- `NOTES.md` — deliverable format, how the brief was verified, open questions
- `LICENSE` — MIT
